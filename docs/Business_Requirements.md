## Project - 1 : Sales Performance Dashboard

1. Import and clean raw sales dataset (remove nulls,
duplicates)
2. Analyze monthly, quarterly, and yearly sales trends
3. Identify top-selling products and low-performing items
4. Perform region-wise and category-wise sales comparison
5. Create KPIs like total revenue, profit, growth rate
6. Build an interactive dashboard using Power BI or Tableau
